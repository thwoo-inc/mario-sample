応用1: 敵を踏んで倒す

マリオのように、敵の上からジャンプして踏みつけると倒せるようにします

この応用で学ぶこと

  • ✓ 衝突の方向を判定する方法（上から？横から？）
  • ✓ ContactPoint2Dで衝突点を取得する
  • ✓ 敵を倒した時のバウンド（跳ね返り）処理

PlayerController.cs の変更

OnCollisionEnter2Dメソッドを以下のように変更します。

追加する変数

[Header("踏みつけ設定")]
[SerializeField]
private float stompBounceForce = 8f;  // 踏んだ後の跳ね返り力

OnCollisionEnter2Dの変更 

private void OnCollisionEnter2D(Collision2D collision)
{
    if (collision.gameObject.CompareTag("Enemy"))
    {
        // 衝突点を取得して、上から踏んだか判定
        // プレイヤーの下端が敵の中心より上にあれば「踏んだ」
        float playerBottom = transform.position.y -
            GetComponent<BoxCollider2D>().bounds.extents.y;
        float enemyCenter = collision.transform.position.y;

        if (playerBottom > enemyCenter)
        {
            // 踏みつけ成功！
            // 敵を倒す
            EnemyController enemy =
                collision.gameObject.GetComponent<EnemyController>();
            if (enemy != null)
            {
                enemy.OnStomped();
            }

            // プレイヤーが少し跳ねる
            rb.linearVelocity = new Vector2(
                rb.linearVelocity.x, stompBounceForce);
        }
        else
        {
            // 横から当たった → ゲームオーバー
            if (GameManager.Instance != null)
            {
                GameManager.Instance.GameOver();
            }
        }
    }
}

EnemyController.cs の変更

踏まれた時の処理メソッドを追加します。 

/// <summary>
/// プレイヤーに踏まれた時の処理
/// </summary>
public void OnStomped()
{
    // 動きを止める
    rb.linearVelocity = Vector2.zero;

    // コライダーを無効化（もう当たらないように）
    GetComponent<BoxCollider2D>().enabled = false;

    // 潰れるアニメーション（Y方向に縮める）
    transform.localScale = new Vector3(
        transform.localScale.x,
        transform.localScale.y * 0.3f,
        transform.localScale.z
    );

    // 少し待ってから消す
    Destroy(gameObject, 0.3f);
}

解説

  • ・bounds.extents.y はコライダーの高さの半分です。これでプレイヤーの足元の位置がわかります
  • ・プレイヤーの足元が敵の中心より上にあれば、上から踏んだと判定します
  • ・踏んだ後は stompBounceForce で上方向の速度を与えて跳ね返ります
  • ・Destroy(gameObject, 0.3f) は0.3秒後にオブジェクトを消します

Unityでの設定

1

PlayerControllerのInspectorでStomp Bounce Forceの値を調整（8くらいがおすすめ）

2

敵にBoxCollider2Dが付いていることを確認

3

プレイして、上からジャンプで倒せるか・横から当たるとゲームオーバーになるかテスト
