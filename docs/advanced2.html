PlayerController.cs の変更

追加する変数

[Header("ダブルジャンプ設定")]
[SerializeField]
private int maxJumpCount = 2;  // 最大ジャンプ回数（2=ダブルジャンプ）

// ジャンプ回数のカウント
private int currentJumpCount = 0;

CheckGroundの変更

private void CheckGround()
{
    // 前のフレームの接地状態を保存
    bool wasGrounded = isGrounded;

    if (groundCheck != null)
    {
        isGrounded = Physics2D.OverlapCircle(
            groundCheck.position, groundCheckRadius, groundLayer);
    }
    else
    {
        isGrounded = Physics2D.OverlapCircle(
            transform.position + Vector3.down * 0.5f,
            groundCheckRadius,
            groundLayer
        );
    }

    // 着地した瞬間にジャンプ回数をリセット
    if (!wasGrounded && isGrounded)
    {
        currentJumpCount = 0;
    }
}

HandleJumpの変更

private void HandleJump()
{
    if (Keyboard.current != null &&
        Keyboard.current.upArrowKey.wasPressedThisFrame &&
        currentJumpCount < maxJumpCount)
    {
        // ジャンプ実行
        rb.linearVelocity = new Vector2(
            rb.linearVelocity.x, jumpForce);
        currentJumpCount++;
    }
}

解説

  • ・maxJumpCount = 2 にすると2段ジャンプ、3にすると3段ジャンプになります
  • ・currentJumpCount はジャンプのたびに1増え、着地で0に戻ります
  • ・wasGrounded と isGrounded を比較して「着地した瞬間」を検出しています
  • ・元の isGrounded 条件を currentJumpCount < maxJumpCount に変えただけ！

追加チャレンジ

  • ・2段目のジャンプ力を少し弱くしてみよう（jumpForce * 0.7f など）
  • ・ダブルジャンプ中は別の色やエフェクトを付けてみよう
  • ・ステージに高い場所を作って、ダブルジャンプでないと届かないアイテムを配置してみよう
